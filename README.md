# Sarah Norris Gyening — Original Art Gallery

This repository is the official website project for an independent artist and her original paintings. The previous holding-company-themed 3D gallery has been replaced in production with a purpose-built art collection and digital exhibition.

## Website
- Responsive artist-focused homepage and collection with all **10 unique original painting photographs** provided for the gallery
- Filters for portraits, flowers, landscapes, still life, and abstract work
- Seven curated digital exhibition rooms, artwork viewer, and inquiry-message preparation
- No invented sale prices, sizes, availability status, or unverified email address

## Source and deployment
The current, editable website source is **`index.html`**, **`styles.css`**, **`script.js`**, and the **`artworks/`** folder at the repository root. The earlier **`src/`** 3D demonstration is obsolete and not used by the production build. Run **`npm run build`** to produce the Vercel deployment output in **`docs/`**. Vercel should use Build Command `npm run build` and Output Directory `docs`.

## Contact note
The inquiry form deliberately **copies a message** instead of pretending to send it. Add Sarah's approved email or a working contact form before accepting public customer inquiries.

Artwork labels are descriptive working labels, not confirmed official titles. Confirm formal titles, sizes, mediums, prices and availability with Sarah before offering items for sale.
